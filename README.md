# Gig Bag

Personal concert journal - log every live show you've been to (artist, venue, city, date, setlist highlights, rating, memory note), browse them as cards sorted newest first, edit or delete any entry. Everything persists in localStorage, no backend, no login.

Jalanin:
```
npm install
npm run dev
```

Test: `npm test` (Vitest). Build/type-check: `npm run build` (`tsc && vite build`).
